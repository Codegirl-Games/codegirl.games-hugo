**Codegirl Games** is a place with a simple mission: build full-feature games while showing others lessons I learned along the way.

I'm not pretending to have all the answers. I'm learning in public: comparing languages on the same project, applying patterns from books like _Game Programming Patterns_, and building a game engine through trial and error.
